NX便捷功能包 v3.4.0 合并模块 NX工具 Htet 2.5.1 + 格式转换 2.1.5 更新日期 2026-11-15 制作者 Wong、Htet、Limulu

本说明覆盖一个工具包、一个模块目录 NX工具：二维出图、快捷打孔、颜色/显示/图层快捷操作、截图/公差查询/计算器等常用工具，以及格式转换（prt / step / igs / x_t 五种方向互转，含 stp / igs / x_t 批量导入为 .prt）。全部功能共用同一个顶层菜单「NX 工具」（English 界面为 NX tools）与同一个功能区选项卡；v3.3.6 起两个原模块的目录已合并为 NX工具，只装一个目录、只写 custom_dirs.dat 一行。

共同原则：不改原 .prt、不删用户图纸；覆盖既有产物前先把原文件备份为同名 .bak（见第 8 节「覆盖与 .bak 备份」）；导入 STEP/IGES/Parasolid 会另存为源目录下的 .prt（.prt 源仅打开、不另存）。执行结束后恢复原来的显示部件、工作部件与部件打开状态。

00安装前必读

  1. 菜单语言自动选。按系统界面语言选（简体→简中、繁中→繁中、其他→英文），系统显示不了时自动退英文、不会写出乱码；英文系统为纯 ASCII 无编码风险，但自 v3.1.6 后未做近期真机验证。
  2. 改过系统区域要先重启。调整过「非 Unicode 程序的语言」后请重启再安装，否则 NX 可能按旧编码读菜单而显示乱码。
  3. 一台电脑只留一份。装新版前先卸载旧版；两份已注册目录会互相覆盖菜单，安装器只告警、不阻断。
  4. 别手动指定不匹配的语言。如繁中系统上用 -Lang zh_cn：会按严格模式校验并列出缺字，不会写入半截乱码。
  5. 先解压到固定文件夹再装。解压后要能同时看到 install.bat 和 NX工具\ 目录，不要在压缩包里直接双击，也不要解压到临时目录或下载目录：安装器不复制文件，包解到哪里，哪里就是安装目录，解到临时路径重启后会被清掉、菜单随之失效。
  6. 装在受保护目录要管理员运行。NX 位于 C:\Program Files 这类受保护目录时，请右键安装器选「以管理员身份运行」，否则写注册文件会因权限不足失败。

快捷打孔用法

  1. 入口：NX 工具 → 常用工具 → 快捷打孔（工具条同）。打开当前工作零件的实体。
  2. 选一个平面作为孔入口面，再用「孔中心」指定点；点会自动投影到该平面。
  3. 选孔型：普通腰孔 / 台阶沉头腰孔；端型：通孔 / 盲孔。腰孔填两端圆心距与方向角。
  4. 可直接选 M3–M12 螺钉规格自动带出孔径与深度，或选「自定义」手填。
  5. 可连续指定点（或点草图入口在入口平面画点），右侧显示已选点数；点「应用」一次打完。方向不对时勾「反转方向」。

仅支持平面入口与当前工作零件的实体；应用前校验孔中心与腰孔两端在实体内，失败自动回退本次减料。

添加螺钉用法

  1. 入口：NX 工具 → 常用工具 → 添加螺钉（工具条同）。打开当前工作零件。
  2. 选一个平面作为螺钉支承面，再指定螺钉位置点；点会自动投影到该平面。
  3. 选规格（M3–M12 或自定义）、头型（圆柱头 / 沉头 / 圆头）与是否通孔；预览确认后点「应用」。
  4. 可连续添加多个位置；方向不对时勾「反转方向」。
换机 / 手工拷贝必看「添加螺钉」与「腰型孔参数化特征」依赖 application\CustomFeatureConfiguration.xml。该文件必须留在 NX工具\application\ 下（即 $UGII_USER_DIR\application\）；只拷 startup\ 或漏掉这个 XML，NX 启动时不会注册自定义特征，按钮点了会没反应或报「找不到特征类」。用安装器安装时无需手工处理。

02安装与升级

本包为一个安装入口 · 一个模块目录 NX工具：双击根目录的图形安装器 NX便捷功能包.exe，只选一次 NX 目录、定一次界面语言；安装器只向 custom_dirs.dat 追加一行（指向 <包根>\NX工具），不再询问或分别安装子模块。

入口 / 场景安装方式说明
整包（推荐）双击根目录 NX便捷功能包.exe，选目录后点「安装插件」安装、升级、卸载都只用这一种方式
无图形界面 / 批处理双击根目录 install.bat与图形安装器同一套逻辑，供脚本或远程环境使用

安装步骤

  1. 解压发布包，保持 NX便捷功能包.exe、install.bat、install.ps1 与 NX工具\ 同处（exe 单独拷走会提示「找不到 install.ps1」）。
  2. 双击根目录 NX便捷功能包.exe，选择含 UGII 的那一层（如 D:\NX2506），点「安装插件」。无图形环境时改用根目录 install.bat。
  3. 界面语言随系统/UGII_LANG 自动判定（简体 / 繁体 / English），默认简体中文。
  4. 看到安装成功提示后重启 NX（菜单与功能区只在启动时加载）。

从 v3.3.5（含更早）升级

  1. 把 v3.3.8 包解压到新的最终位置（建议新目录，避免覆盖仍在使用的旧包）。
  2. 运行新包根目录的 NX便捷功能包.exe（或 install.bat），选同一个 NX 安装目录，点「安装插件」。
  3. 安装器会自动：追加 NX工具 一行 → 摘掉旧的 Htet工具 / 格式转换 两行 → 按当前码页重写语言资源。旧的两个模块目录原地保留、不删任何用户文件。
  4. 如果新包与旧包在同一个父目录（如都在 D:\NX2506\NX便捷功能包），安装器会直接移除旧两行；升级完成后旧目录 Htet工具\、格式转换\ 可手动移走或删除（其中 logs\ 等用户产物请先自行备份）。
  5. 重启 NX 验证「NX 工具」菜单 31 项与功能区 6 组按钮；确认无误后再清理旧目录。
包根即安装目录安装器只写注册文件、不改动包内文件，所以 install.bat 所在目录就是安装目录：要先解压到最终位置，再在该目录运行安装器。
旧版清理安装前会自动识别并移除可识别的旧包注册行（叶子名为 Htet工具 / 格式转换 / 批量导入导出 / nx tools / nx_step_export / NX便捷功能包，或其 startup\ 下含本工具包菜单文件的行），只删注册行，目录与其他行原样保留。

安装器改了什么

  • 只向 <NX>\UGII\menus\custom_dirs.dat 追加一行 <包根>\NX工具，不动其它行；写前备份 .nxbat.bak，写后恢复只读，界面显示前后字节数与 SHA256；重复安装幂等（已存在则不重复写入）。
  • 按所选语言把 NX工具\lang\ 下的菜单/工具条/功能区母本按当前码页转码写入 startup\ 与 application\profiles\All\NX_tools.rtb（六组合并为单一选项卡），并做读回自检；application\ 下的 .py / .vb 与对话框、螺钉图标一并部署到 startup\。
  • UGII_USER_DIR 为空时设为插件根 NX工具，写 install_env_state.json 记录原值，卸载时删除或恢复；已指向别处则不覆盖、只告警。若原值指向本插件的历史副本（旧的 Htet工具 目录），则自动接管。
注意其它安装器可能把 custom_dirs.dat 整份还原成模板、抹掉本插件的行；重跑本插件安装器即可补回，不必卸载重装。

安装日志见第 11 节（追加写入，卸载不删）。

命名约定界面显示名为「NX 工具 / NX tools」；脚本、按钮 ID、图标名保持 Htet_* 不变（快捷打孔沿用 Quickhole.py / Quickhole.dlx，旧 hbt_* 兼容见第 10 节）。格式转换的按钮动作为单一入口 format_convert.py。

04界面语言

菜单、工具条、对话框与日志关键字均支持简中、繁中、英文；「快捷打孔」菜单项随语言切换，但其 BlockStyler 对话框目前只有一份中文母本；「截图工具」的运行提示目前为简体中文。安装时按下列顺序判定，命中即停：

优先级来源映射
1命令行 -Langzh_cn / zh_tw / en
2UGII_LANGsimpl_chinese、schinese → 简中；trad_chinese、chinese → 繁中；english → 英文
3系统界面语言zh-CN / zh-Hans / zh_hans → 简中；zh-TW / zh-HK / zh-Hant / zh_hant → 繁中
4以上都不是英文

装错语言不用改文件，重跑安装器指定语言并重启 NX：

powershell -ExecutionPolicy Bypass -File install.ps1 -NxDir "D:\NX2506" -Lang zh_cn

  • lang\ 母本统一 UTF-8，安装时按系统默认 locale 的 ANSI 码页（GetSystemDefaultLCID，系统区域改动后需重启才刷新）转码写入 startup\；代码页无法表示所选语言时回退 GBK(936)，并提示建议改用英文。
  • 代码页能力按语言分别判定：简中用简体样本、繁中用繁体样本。CP936 简繁都能显示；CP950（繁体 Windows）只能显示繁体，系统 UI 为繁体时默认 zh_tw、不提示；CP932 / CP1252 中文都不可显示，默认回落 lang\en 并提示。检测与选择结果写入 %TEMP%\NX便捷功能包_install.log（含 can_zh_cn / can_zh_tw / probe / candidate / feasible / lang / auto_switched，以及 sys_default_lcid / lcid_codepage / lcid_locale / sys_codepage / cp_reason）。
  • 运行时窗口文字按进程内 UGII_LANG 选取，缺项回落英文；菜单仍按安装时语言。
  • Quickhole.dlx 不区分语言（单份中文母本），安装时随 Quickhole.py 原样部署到 startup\，不做转码。
  • 两插件须同语言，否则「顶层中文 + 子级联英文」混排（顶层标签由后加载者决定）。

05自动出图

入口：NX 工具 → 出图 → 自动出图（工具条同）。先打开 .prt，点菜单弹出「自动出图 - 选择实体」，可多选实体，确定即开始；点取消＝不处理。

名称原「批量出图」已更名为「自动出图」，在 NX 内直接出图，不依赖 AutoCAD。

作用：为每个选中实体生成一套三视图（主视 / 侧视 / 俯视），所有组横向排成一行放在同一张图纸上；主视图标注长、宽，俯视图标注厚度，保留一位小数。

操作五步

  1. 在 NX 打开零件，确认它是当前工作部件。
  2. 点自动出图，在「自动出图 - 选择实体」里多选要出图的实体（可框选、可多选）。
  3. 工具自动切到制图应用，按批刷新界面，能看到视图逐步生成。
  4. 每个实体生成一张图纸，图纸名 AD-1、AD-2…，幅面按一行所需宽度自定义，套 A0 模板。
  5. 结束后不弹完成框；成功/失败组数与逐实体校验明细写入 logs\Htet_autodwg.log。校验出现 FAIL、视图重叠或错误行时，同一份报告才会显示在 NX 信息窗口。

08格式转换

入口：NX 工具 → 常用工具 → 格式转换。流程固定为三步：选择内容 → 核对清单 → 开始转换。全程只有两个弹窗，标题固定为「格式转换」与「确认转换文件」。

  • 5 个方向：prt→stp、prt→igs、stp/igs→prt、x_t/x_b→prt、任意→stp/igs；prt↔stp 组置顶，第二行另列 x_t/x_b→stp、x_t/x_b→igs；底部原 x_t/x_b 提示文字已删除。
  • x_t / x_b 先导入临时件再导出，源文件不改动。
  • stp / igs → prt、x_t / x_b → prt 即原「批量导入」：每个文件独立成部件并全部显示，不塞进当前工作部件。
入口说明自 v3.3.0 起「格式转换」并入「NX 工具 → 常用工具」，没有单独的「批量导入」按钮或子菜单。原「批量导入」的图标 batch_import.bmp 已在 v3.2.1 移除；导入、导出与后台执行器现已合并为单文件入口 format_convert.py，菜单与工具条都只指向它，文件自身包含导入函数与并发执行逻辑，不再依赖同目录其它 .py。

第一步：选择内容

左侧目录树，右侧列当前目录的可转换文件（.prt / .stp / .step / .igs / .iges / .x_t / .x_b），下方为已选清单。「加入文件夹」含子目录；双击文件只加单个。「输出目录」组两个单选项一行两列：「输出到源文件目录」在左，「输出到指定目录」在右，路径框在其下。

第二步：核对清单

  • 自动弹预览窗口（内置试跑），逐行显示「源文件 → 转换后名称 → 状态」。
  • 覆盖列只对已存在目标开放，默认不勾；有未保存修改时逐行询问：勾选＝先保存再导出，不勾＝跳过。

第三步：导出

  • 按磁盘上的 .prt 生成 STEP/IGES；判断可见图层时临时切显示部件，结束后恢复原显示/工作部件。
  • 只导出当前工作视图可见图层上的几何（按视图内可见性判定，不是图层全局开关）；隐藏层实体不进 STEP，装配体同样适用。
  • 输出默认到源文件目录，也可指定统一目录（无效时回落原路径并记日志）。
  • 后台执行：进度窗可点走或最小化，不置顶；期间 NX 前台可继续操作；「同时执行数」默认 2（1~6 可调）。

转换成功后的打开选项

  • 仅产物为 .prt 的方向生效：整批结束后可选「打开转换后的文件」，默认不勾选；勾选则自动打开本批成功的 .prt，失败或跳过的不打开，已在会话中的不重复打开；导出方向不出现该选项。原「打开上次导入结果」入口已移除。

停止与进度窗

  • 点「停止」会清理本次已生成与本批未成功的文件，然后直接关闭弹窗；弹窗无「关闭」按钮，结束后用右上角 × 关闭。
  • 进度窗随 NX 退出一起关闭，包括转换已结束、仅剩进度窗时再关 NX 的情况。

覆盖与 .bak 备份

备份规则只要某个产物已经存在且当前是「同名已存在 = 覆盖」，覆盖动作发生前会先把原文件完整复制一份，名称为原文件名加 .bak，放在同一目录：D:\out\顶盖.step → D:\out\顶盖.step.bak。同名 .bak 已存在时直接覆盖它（保留最近一次的原件，不会无限累积）。
  • 备份失败即中止：磁盘满、只读、被占用等导致复制不成功时，本次覆盖不执行，原文件保持原样，该行记为失败并在日志写明原因 —— 不会出现「没备份就覆盖」。
  • 停止 / 回滚不删 .bak：中途点「停止」触发回滚时，只删除本次新生成的产物（原本不存在的那些），覆盖模式下的目标文件与 .bak 都保留，方便对照。
  • 导入侧同一口径：stp / igs / x_t → prt 方向若目标 .prt 已存在且为覆盖，同样先把原 .prt 备份为 同名.prt.bak 再保存；保存失败会用 .bak 还原目标，.bak 保留不删。
  • 清理方式：.bak 是纯副本，脚本不自动清理。确认新产物无误后，在资源管理器搜索 *.bak（或 *.step.bak / *.igs.bak / *.prt.bak）手动删除即可；长期覆盖同一批文件时每份只占一个 .bak 的空间。

12已知限制

1. 图纸树可能显示过期标记（红叉）

出图后图纸树可能显示红叉（NX 自带过期标记，公共 API 无法清除），不影响视图、尺寸与图纸内容，刷新或重开即消失。出图后不要对图纸执行「更新」，强制更新仍可能把全部实体重新吸收进视图。

2. 「抑制视图更新」是会话级偏好

出图期间工具会打开 NX「抑制视图更新」偏好；该偏好是会话级的，进制图/切回建模时被 NX 复位，工具按需重开，重启 NX 后恢复默认。

如需 NX 自动视图更新（如改模型后视图跟着更新），在首选项 → 制图 → 视图 → 更新里取消勾选「抑制视图更新」，或重启 NX 后再操作。

3. 快捷打孔只处理当前工作零件的平面

入口面必须是平面，组件需先设为工作零件；可连续「添加孔中心」后一次应用，支持「清空中心」与中心计数。孔方向沿入口面法向向内，可用「反转方向」；腰孔两端也须落在实体内。对话框目前为中文。

4. 自动出图会不断新增图纸

每次运行新建 AD-1、AD-2…，不覆盖也不清理旧图纸；同一个零件反复出图，图纸会持续累积。不需要的图纸请手动删除。建模视图（名字带时间戳）同理保留在部件导航器中。

5. 自动出图单行有宽度上限

所有组横向排一行，图纸宽度上限 MAX_ROW_SHEET_W = 6000 mm；实体很多时会整体缩小比例（最小 1:200），可能小到看不清。建议分批选实体，或按需调大该常量。当前版本不做自动换行/分页。

另外两点本版未提供 Ribbon 页签（NX 2506 嵌套菜单页签为空，只保留经典菜单与工具条）；Windows 路径超过 260 字符时 NX 无法访问，请把项目放到层级更浅的目录。
