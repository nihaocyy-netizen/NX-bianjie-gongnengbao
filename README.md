# NX便捷功能包-Htet-Zhang

适用于 Siemens NX 2506 的综合工具包，统一提供二维出图、快捷打孔、螺钉添加、颜色与显示、图层管理、常用工具和 CAD 格式转换功能。

## 功能概览

- **自动出图**：多选实体生成主视、侧视、俯视图，自动排列并标注长、宽、厚。
- **逐件出图**：一次处理一个实体，便于手动调整视图和标注。
- **快捷打孔**：在平面上批量创建普通腰孔或台阶沉头腰孔，支持 M3–M12 规格和自定义参数。
- **添加螺钉**：快速放置圆柱头、沉头或圆头螺钉，支持连续添加和方向反转。
- **颜色与显示**：固定颜色、随机改色、半透明、取消透明、仅显示选中实体。
- **图层管理**：打开或关闭全部图层、上一/下一图层、实体分层、切换工作层、移动到 255 层。
- **常用工具**：打开文件所在目录、截图、公差查询和计算器。
- **格式转换**：支持 PRT、STEP/STP、IGES/IGS、Parasolid X_T/X_B 之间的批量导入导出，支持预览、同名处理、输出目录和并发设置。
- **多语言菜单**：简体中文、繁体中文和英文菜单按系统环境自动选择。

## 安装

1. 解压整个发布包到固定目录，保持 `NX便捷功能包.exe`、`install.bat`、`install.ps1` 和 `NX工具` 目录位于同一层。
2. 关闭正在运行的 NX。
3. 双击根目录的 `NX便捷功能包.exe`，选择包含 `UGII` 文件夹的 NX 安装目录。
4. 点击“安装插件”，安装器会把 `NX工具` 注册到 NX 的 `custom_dirs.dat`。
5. 重新启动 NX，菜单栏中出现“NX 工具”后即可使用。

NX 安装在 `C:\Program Files` 等受保护目录时，请以管理员身份运行安装器。无图形界面时可运行 `install.bat`。

## 使用

安装完成后，在 NX 菜单或工具条中打开“NX 工具”，选择对应功能并按界面提示操作。涉及模型的命令通常需要先选择实体或平面。

格式转换的一般流程：选择转换方向 → 添加文件或目录 → 设置同名处理和输出目录 → 预览清单 → 开始转换。STEP 导出需要 NX STEP Translator 许可，IGES 导出需要 NX IGES 转换器可用。

## 重要说明

- 安装器只注册插件目录，不复制包内文件；解压后的目录必须保持不变。
- 添加螺钉和参数化腰孔依赖 `NX工具/application/CustomFeatureConfiguration.xml`，请勿单独移动或删除。
- 转换覆盖既有文件前会创建同名 `.bak` 备份；日志和临时文件位于插件目录的 `logs` 或 Windows 临时目录。
- 工具尽量恢复原来的显示部件、工作部件和打开状态，不修改原始 PRT 文件内容，除非用户明确选择保存或覆盖。
- 升级前建议先卸载旧版本，再安装新版本；一台电脑建议只保留一份注册插件目录。

## 卸载

关闭 NX 后运行根目录的 `uninstall.bat`，或使用 `NX便捷功能包.exe` 中的卸载功能。卸载只移除插件注册项，不删除用户生成的模型、图纸和备份文件。

## 目录结构

```text
NX便捷功能包/
├─ NX便捷功能包.exe   图形安装器
├─ install.bat         批处理安装入口
├─ install.ps1         安装脚本
├─ uninstall.bat       卸载入口
├─ NX工具/             NX 菜单、脚本、界面和图标
│  ├─ application/
│  ├─ bitmap/
│  ├─ lang/
│  └─ startup/
└─ 使用说明.html       完整图文说明
```
